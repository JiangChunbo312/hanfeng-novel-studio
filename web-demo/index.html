项目详情

恋综编剧她只想搞钱

核心设定

林满月是濒临失业的恋综小编剧，意外觉醒"弹幕视觉"，能实时看见观众的心动值和吐槽弹幕。她靠预判弹幕改写剧本，把无人看好的糊综做成爆款。

文风要求

轻快爽利、高密度对话、章节末留钩子；第三人称女主视角为主。

硬性禁忌

不写重生老套金手指；不涉及政治法律；不写真实明星影射；不写低俗擦边。

模型配置

只认 OpenAI 兼容协议。填 Base URL + Key + 模型名即可接入；按角色路由不同模型以控制成本。

⚠️ 在线演示不含任何 API Key。本页完整展示配置功能框架，所有内容为占位示例。本地运行时，你的 Key 只保存在 config.local.json，不会上传到任何服务器。
