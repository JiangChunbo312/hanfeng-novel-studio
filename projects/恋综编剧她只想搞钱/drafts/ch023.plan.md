【本章功能】收束机房危机，转入安全区分析证据，揭示“系统”实验性质，完成卷一阶段性转折。
【核心冲突】林满月与“系统控制机制”的对抗（生理异变 vs 自由意志）；陆淮舟知情不报引发的信任危机与利益同盟重构。
【场景清单】
1. 地下二层通风管道出口 -> 林满月、陆助理 -> 利用检修梯撤离，避开安保队封锁路线。
2. 陆淮舟私人防弹车内 -> 林满月、陆淮舟 -> 读取硬盘数据，处理掌心伤口，进行关键对话摊牌。
3. 热搜话题后台（手机界面） -> 林满月、小鹿（语音连线） -> 监控舆论发酵情况，发现异常流量清洗指令。
【必须发生】
1. 林满月掌心血迹自动愈合，皮下浮现淡蓝色微光纹路，证实身体已被系统标记同化。
2. 硬盘解密成功，显示《心动倒计时》实为“情绪操控服从度测试”，总监仅是第 7 个失败执行者。
3. 陆淮舟承认自己是“观察员”之一，解释此前隐瞒是为了防止她过早崩溃，两人关系由利用转为共谋。
4. 直播事故视频虽被平台下架，但通过粉丝站私域流量扩散，舆论风向开始逆转支持编剧。

3. 不要出现新的肢体暴力冲突，重点在于信息博弈和心理层面的冲击与重建。
