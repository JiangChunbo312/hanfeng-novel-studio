【本章功能】
本章是卷一“糊综救场”的收尾转折章，承担“收网”与“身份反转”的双重功能：林满月从调查者变为被猎杀者，陆淮舟从保护者暴露为布局者，弹幕系统从工具升格为规则本身。

【核心冲突】
林满月与“第四页约定”的冲突——她以为自己是主导调查的编剧，实则是被约定绑定的棋子；她与陆淮舟的信任关系濒临破裂；她与陌生发信人（潜在幕后黑手）的对峙即将引爆。

【场景清单】
1. 地库风井出口 → 林满月、陆助理（短信引导）→ 林满月在黑暗中独行，灯光逐盏熄灭，心理防线崩塌。
2. 台门口接应点 → 林满月、陆淮舟 → 陆淮舟当面承认“推进陷阱”，林满月质问立场，两人对峙升级。
3. 电梯厅 → 林满月、蓝V弹幕（视觉闪现）→ 弹幕再次出现，暗示系统意志介入。
4. 编剧办公室 → 林满月、小鹿（远程）→ 林满月整理证据本，标注“第四页约定”为新核心矛盾，准备应对倒计时终结。

【必须发生】
1. 林满月必须在黑暗中完成“从调查者到猎物”的心理转变，具体表现为她主动拨通陆淮舟电话并质问。
2. 陆淮舟必须当面或通过电话明确说出“我可能已经把你推进了陷阱”，不可回避或模糊。
3. 必须回收伏笔H084（第四页约定生效），明确其“屏蔽心动值”机制已启动，林满月已无法看见陆淮舟的心动值。
4. 必须触发倒计时剩余不足12小时的紧迫感，林满月必须做出“是否继续追查”的抉择。
5. 必须出现一次弹幕系统异常（如蓝V字闪现、心动值标签消失或乱码），暗示系统已感知林满月的“越界”。

【必须规避】
1. 不要写林满月直接找到陌生发信人或综艺部总监——他们不在本章出场，保持神秘。
2. 不要让陆淮舟解释“陷阱”的具体内容——保留悬念，不提前揭晓。
3. 不要重复使用“灯光熄灭”“电话挂断”等已用过的惊悚桥段，本章情绪转向“认知崩塌”而非“物理威胁”。
4. 不要让林满月在本章获得任何新证据或新线索——她已掌握全部信息，本章是“消化与崩塌”章。

【承接要求】
开头直接承接上一章结尾的黑暗与沉默，从“她没动”切入，用“拨号键按下”作为情绪爆发点，语气从压抑转为锐利质问，情绪从困惑转向愤怒与背叛感。

【钩子设计】
章末钩子：林满月在办公室整理证据本时，发现弹幕系统中陆淮舟的心动值标签彻底消失，同时弹幕区刷过一行蓝V字：“你终于明白，你从来不是编剧，是剧本。”——她意识到，自己可能从头到尾都在被系统操控。

【伏笔动作】
- 回收H084：第四页约定正式生效，陆淮舟心动值屏蔽启动，林满月验证“近距离递信封时标签纹丝不动”为约定生效标志。
- 回收H087：蓝V弹幕“你终于知道，为什么他从不让你查到底”与本章新弹幕形成闭环，暗示蓝V为系统意志化身。
- 新埋H089：弹幕系统开始主动干预林满月的感知，她发现“弹幕视觉”出现延迟、乱码或选择性屏蔽，暗示系统已觉醒或被操控。
- 新埋H090：陆淮舟的“陷阱”可能并非物理伤害，而是“让她成为全网公敌”或“让她亲手毁掉自己的编剧生涯”，为卷二“弹幕反噬”埋线。
- 新埋H091：倒计时剩余11小时58分，但林满月发现倒计时显示的数字与手机系统时间不同步，暗示倒计时本身可能是弹幕系统制造的幻觉。
