【本章功能】反转：本章承接第19章的证据闭环，从报告归档、咖啡联想切入，经电梯蓝V"别回头"警告，进入地库风井检修点，发现牛皮纸信封（U盘+笔记本页），揭示"第四页约定"的另一半——陆淮舟自愿成为林满月的"弹幕屏蔽器"，同时收到匿名短信"你查到底了，轮到我了"，引爆身份反转：林满月从调查者变为被猎杀者。

【核心冲突】林满月与"第四页约定"另一半真相的正面相撞——她以为陆淮舟在帮她查真相，实则是被约定绑定的棋子；弹幕系统通过蓝V字与"别回头"指令实施实时压制；她与陌生发信人（潜在幕后黑手）的对峙即将引爆。

【场景清单】
1. 工位 + 茶水间：报告写完归档，林满月冲咖啡，从咖啡颜色联想到地库初遇，倒计时剩12小时03分，收到蓝V弹幕"你终于知道，为什么他从不让你查到底"与陆淮舟"别回头"。
2. 电梯下行：林满月理帆布袋，取出陆淮舟手绘风井俯视图，在背面"那天有人比你先到"下写下"那个人，是不是你？"，倒计时剩11小时58分。
3. 地库斜坡东侧（旧监控盲区）风井检修点：林满月发现黑色塑料袋中的牛皮纸信封，内藏U盘与笔记本页"第四页约定完整记录"，揭示"弹幕屏蔽器"约定生效条件，收到匿名短信"你查到底了，轮到我了"。
4. 地库灯灭 + 电话：林满月拨通陆淮舟电话质问立场，陆淮舟承认"我可能已经把你推进了陷阱"，陆助理短信引导离开，地库灯全灭。

【必须发生】
1. 林满月必须在风井检修点发现新证据（牛皮纸信封：U盘+笔记本页），将调查推向更高层级。
2. 必须揭示"第四页约定"的另一半内容——陆淮舟自愿成为"弹幕屏蔽器"，完成H038/H051/H057伏笔回收。
3. 必须收到匿名短信"你查到底了，轮到我了"，引爆"从调查者到被猎杀者"的身份反转。
4. 陆淮舟必须通过电话明确说出"我可能已经把你推进了陷阱"，不可回避或模糊。
5. 必须出现一次弹幕系统异常（蓝V字闪现后碎裂），暗示系统已感知林满月的"越界"。

【必须规避】
1. 避免让总监或陌生发信人直接出场——他们保持神秘，为下一章留白。
2. 避免陆淮舟解释"陷阱"的具体内容——保留悬念，不提前揭晓。
3. 避免重复使用"电梯弹幕闪现"作为唯一信息提示——本章需以物理证据（牛皮纸信封、笔记本页）作为新线索载体。
4. 避免让"弹幕视觉"能力失控——保持其"可控但不可靠"的设定。
5. 避免林满月"顿悟"式得出结论——她必须通过破解U盘、回看笔记本页的具体动作推进。

【承接要求】
从上一章结尾"长出一口气，然后开始写报告"切入，承接证据闭环的短暂松懈，经"报告写完"、咖啡联想的情绪余韵，迅速转入被监视的紧绷感，通过电梯、地库的动线推进到风井发现，保持林满月"理性中带直觉"的行动基调。

【钩子设计】
章末钩子：林满月拨通陆淮舟电话，陆淮舟说"我可能已经把你推进了陷阱"，电话挂断；陆助理短信引导她离开地库，地库灯全灭——她从调查者沦为被猎杀者，而陆淮舟的"保护"可能正是最大的陷阱。
