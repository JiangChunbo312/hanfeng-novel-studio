【本章功能】
本章是卷一“糊综救场”的收网章节，承担**转折**与**收网**双重功能——完成对王丽伪造签名事件的证据闭环，引爆综艺部总监这条暗线，同时将林满月从“被动调查者”推入“主动设局者”，为卷二“爆款制造机”中她反将一军、掌控制作人话语权埋下决定性伏笔。

【核心冲突】
林满月 vs. 综艺部总监（幕后操控者）+ 陆淮舟（信息不对等的盟友）+ 自身弹幕视觉的局限性。焦点在于：**弹幕能剧透观众喜好，却无法控制真实心动**——她靠数据预判人心，却在真相面前发现人心比数据更不可控。

【场景清单】
1. 技术部工位 + 林满月、小鹿：林满月整合全部线索，小鹿导出总监办公室电脑IP的完整访问日志，发现19:25“查询”操作后紧跟一次“导出”行为，目标为“鱼饵-勿删.mp4”。
2. 消防通道楼梯间 + 林满月、陆淮舟：林满月出示新证据，陆淮舟承认自己早于她一小时到过风井检修点，但拒绝说明身份；林满月要求他交出SD卡原始备份，陆淮舟提出“用一次真实心动换一次真相”。
3. 台内资料室 + 林满月：林满月调取9月26日人力系统日志，发现总监办公室IP在她入职当天下载简历后，立即访问了“第四页文件”模板库，确认布局早于她入职。
4. 公寓楼下大堂 + 林满月、未知跟踪者（镜头视角）：林满月离开台里返回公寓，电梯内弹幕闪现“他就在你身后”，她未回头，但手机收到陆淮舟发来的一段10秒视频——画面是她工位监控视角，时间戳为三分钟前，视频末尾陆淮舟低声说：“你查的那个人，是我爸。”

【必须发生】
1. 小鹿必须导出总监办公室IP的“导出”操作记录，证明其不仅“查询”鱼饵文件，实际已获取副本。
2. 林满月必须发现总监办公室IP在9月26日下载她简历后立即访问“第四页文件”模板库，确认伪造签名布局早于她入职两周。
3. 陆淮舟必须在楼梯间提出“用一次真实心动换一次真相”的交易，且必须拒绝说明自己为何早于林满月到风井。
4. 林满月必须在公寓电梯内收到陆淮舟发来的10秒监控视频，视频结尾必须揭示“你查的那个人，是我爸”。
5. 必须回收伏笔H052（第四页文件创建时间早于入职）、H068（布局目的）、H079（手绘图背面“有人比你先到”）、H081（F070编号含义）。

【必须规避】
1. 不要让林满月直接对峙综艺部总监——他未出场，只能通过数据和间接证据逼近。
2. 不要写陆淮舟直接交代全部真相——保留信息不对等，维持“他手里到底握着什么”的悬念。
3. 不要重复使用“弹幕闪现提示”作为唯一信息手段——本章必须用技术日志、人力系统记录、监控视频等硬证据推进。
4. 不要写林满月“感到震惊”“内心翻涌”等空泛情绪——用具体动作表现：她盯着视频末尾的字，手指反复放大画面，然后把手机塞进帆布袋最底层，拉链拉到底。

【承接要求】
接上一章结尾“收到”二字，从林满月调暗屏幕、开始整理线索切入。语气冷静、克制，但暗流涌动。她刚收到威胁短信，又收到陆淮舟“别回头”的警告，此刻必须在“继续查”与“保命”之间做出选择。本章开头她已选择“继续查”，但动作更谨慎——她先冲咖啡，是用熟悉仪式安抚情绪，再开始工作。情绪从“表面镇定”过渡到“数据-driven的冷静”，最终在电梯视频 revelation 时被瞬间击穿。

【钩子设计】
章末悬念：林满月在电梯内收到陆淮舟发来的10秒监控视频，画面是她工位视角，时间戳为三分钟前。视频末尾，陆淮舟低声说：“你查的那个人，是我爸。”她没回头，但电梯门关闭瞬间，弹幕闪现一行蓝V认证字：“你终于知道，为什么他从不让你查到底。”

【伏笔动作】
- 回收：H052（第四页文件创建时间早于入职，确认布局者为总监）、H068（布局目的：为林满月入职后设陷阱，争夺制作人位置）、H079（手绘图背面“有人比你先到”——那个人是陆淮舟本人，他早于她到过风井）、H081（F070：F=风井，070=总监办公室房间号，总监与风井检修点直接关联）。
- 新埋：H084（陆淮舟父亲是综艺部总监，他提供证据是为“自保+设局”，而非单纯合作）；H085（电梯弹幕蓝V字暗示弹幕系统已能主动干预现实，突破“仅视觉”限制）；H086（陆淮舟视频中“你查的那个人，是我爸”——他是否早已知悉父亲是幕后黑手？他提供证据是陷阱还是真心？）；H087（林满月将手机塞进帆布袋最底层，暗示她开始隐藏关键证据，不再完全依赖公开渠道）。
