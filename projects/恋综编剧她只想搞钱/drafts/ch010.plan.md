# 第 10 章 写作意图

【本章功能】
转折——林满月在王姐办公室打出笔迹鉴定这张牌，逼迫王丽作废责任书；陆淮舟兑现"第四页的约定"，递出第四页原件扫描件，文件创建时间戳早于林满月入职两周——局面从"林满月单防周明"翻转为"有人在她入职前就布好了局"。

【核心冲突】
林满月 vs 王丽——围绕责任书存废与伪造签名处理权的正面交锋；表层是职场权力博弈，底层是周明背后是否有更大布局。陆淮舟以第三方力量介入，打破两人僵局。

【场景清单】
1. 王姐办公室（9:00-9:25） / 林满月、王丽 / 林满月出示笔迹鉴定结果要求责任书作废，王丽以"单方送检、不影响节目"压回；林满月亮出导播台后门照片二次施压，王丽瞳孔收缩但拒绝解释端口号；陆助理敲门送来陆方函件，援引合同附件第四页条款要求48小时内书面确认编剧负责人权限，王丽被迫当场作废责任书并签宣发主导权确认。
2. 走廊电梯口（9:30） / 林满月、陆淮舟 / 陆淮舟等在电梯口，递来牛皮纸信封，说"第四页的约定，我只兑现一半"；信封内是第四页原件扫描件，签名栏已有"林满月"三字，文件属性创建时间比林满月入职早两周。他转身走，标签不闪。

【必须发生】
1. 林满月将笔迹鉴定回执截图正面朝上推到王丽桌面，王丽看完后沉默超过五秒——这是她第一次在林满月面前没有立刻接话。
2. 林满月亮出导播台后门照片时，王丽视线在端口号上停了一瞬，随即把照片扣过去推回，说"这个跟今天的事无关"——她认出了端口号但选择压下。
3. 陆助理送来的陆方函件援引合同附件第四页"编剧负责人书面确认"条款，要求48小时内确认权限边界，否则启动艺人方违约审查；王丽看完后当着林满月的面从抽屉取出责任书撕成两半丢进废纸篓。
4. 陆淮舟在电梯口递出牛皮纸信封，林满月打开看到第四页原件扫描件签名栏已有自己名字，翻看文件属性创建时间——比她入职日期早两周。她说"这页纸在我来之前就有了"，陆淮舟没回头。
5. 林满月回到车上，蓝V弹幕飘过一行字："你以为你是来救场的，其实你是被安排来救场的。"她把信封和鉴定回执并排放在腿上，没有发动车。

【必须规避】
- 不让林满月亮出SD卡第11帧"地库第二个人"——这张牌留到后续，本章底牌只打到笔迹鉴定+导播台后门这一层。
- 不让陆淮舟解释风井图含义、标签闪动原因、他为何出现在地库——他只兑现"第四页的约定"这一件事，其余继续留白。
- 不让周明本人在场——他通过王丽的反应间接呈现，不出面不发声。
- 不写感情线甜度或心动描写，本章专注博弈节奏；陆淮舟递信封时标签不闪，刻意制造"近距离但不闪"的反常，不做解释。
- 不让王丽彻底倒台——她让步（撕责任书、签确认书），但压住导播台端口号这条线不松手，保留后手。

【承接要求】
开头直接从上一章结尾"明天王姐办公室，九点"跳切到次日上午九点。林满月坐在王丽对面，帆布袋放在膝上，暗袋里的证据硌着腿。第一句写她把手机正面朝上推过桌面，屏幕上是笔迹鉴定回执截图。语气从上一章的疲惫沉思直接切入冷静出击，节奏从慢转快，不写路上、不写进门、不写寒暄。

【钩子设计】
章末林满月坐在车里，腿上并排放着两样东西：笔迹鉴定回执和第四页原件扫描件。鉴定回执证明签名是假的，扫描件证明假的签名在她入职前就已经写好。两份证据指向同一个结论：有人在她来之前就用她的名字设好了局。蓝V弹幕飘过"你以为你是来救场的，其实你是被安排来救场的"。小鹿从后视镜看她，她没闭眼，盯着手机屏幕上弹幕消失后的空白——但这一次，弹幕没有完全消失，残留了半个字就断了，像是被人掐断的。

【伏笔动作】
- 回收H028：责任书走向明确——王丽当面撕毁，宣发主导权书面确认归林满月。
- 回收H038：第四页的约定兑现——陆淮舟递出第四页原件扫描件，但只给一半信息（文件本身），不给另一半（他如何拿到、为何持有）。
- 回收H048：笔迹鉴定结果在王姐办公室作为核心筹码使用，迫使王丽让步。
- 推进H045：导播台后门照片亮出，王丽认出端口号但压下不解释——端口号来源指向更深层。
- 推进H047：陆淮舟手中信息部分揭示（第四页原件扫描件），但只兑现一半，他到底握着什么仍不完全明朗。
- 新埋H050：第四页原件扫描件文件创建时间早于林满月入职两周，签名栏已有"林满月"——谁在她入职前就用她的名字布局，目的是什么。
- 新埋H051：王丽看到导播台后门端口号时认出来源但选择沉默——她知道那个端口号指向谁，这个知情不报本身就是态度。
- 新埋H052：陆淮舟递信封时标签不闪——首次出现近距离接触但标签保持0的情况，打破此前总结的规律，原因未明。
- 新埋H053：蓝V弹幕"你以为你是来救场的，其实你是被安排来救场的"——暗示林满月入职本身可能是被安排的，与H006（王姐称知道林满月家有存款）形成呼应链。
