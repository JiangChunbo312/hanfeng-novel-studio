# 命名要求
1. 输出**只有标题本身**，不要「第X章」前缀、不要引号、不要编号、不要解释、不要换行。
2. 长度 4–15 个汉字（或等长的短语），要能点出本章最核心的冲突/转折。
3. **标题必须结合本章的钩子**：优先从「本章正文结尾」里抓本章最后落下的那个钩子（一个人出现 / 一句话 / 一个物件 / 一个反常），把它提炼进标题——让人一看到标题就想知道接下来发生什么。如果结尾钩子不够鲜明，再从写作意图和活跃伏笔里找本章最核心的悬念点。
4. 避免与前几章标题雷同；同一本书里相邻章节标题不要撞词。
5. 题材是网文/类型小说，标题要抓人、有张力，可带悬念或反差，不要写成「本章概要」或「XX登场」这种说明句。
