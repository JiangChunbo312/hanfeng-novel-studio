# 输出格式

  "issues": [
    {"id": "A5", "level": "critical|major|minor", "desc": "问题描述", "evidence": "正文原文片段", "fix": "具体怎么改"}

判定规则：
- critical：不修就会穿帮或断链，必须拦下重改（人设冲突、物品凭空出现、时间线矛盾、字数严重不足）
- major：明显瑕疵，建议改（节奏注水、钩子缺失、卷纲偏移）
- minor：可改可不改，留给人工决定
- 没有任何 critical 才视为通过。不许为了给高分而隐瞒问题，也不许为了显得严格而编造问题。
