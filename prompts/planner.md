# 输出格式（严格遵循，不要加多余解释）

【核心冲突】本章的矛盾焦点是什么，谁和谁（或与什么）冲突

【必须规避】2-4 条，不要写的东西（节奏雷区 / 已用过的桥段 / 人设红线）
